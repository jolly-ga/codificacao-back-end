

# 🚀 Codificação Back-End

Bem-vindo(a) ao repositório **Codificação Back-End**! Este espaço é dedicado ao estudo, prática e desenvolvimento de aplicações no lado do servidor (*server-side*), com foco na construção de APIs eficientes e estruturadas.

---

## 🎯 Objetivos

- **Domínio da Linguagem:** Aprofundar os conhecimentos em JavaScript voltado para execução no servidor com Node.js.
- **Construção de APIs:** Desenvolver APIs RESTful utilizando o framework Express.
- **Gerenciamento de Pacotes:** Utilizar o NPM para gestão de dependências e scripts de automação.
- **Controle de Versão:** Registrar a evolução dos projetos e práticas utilizando Git e GitHub.
- **Boas Práticas:** Aplicar conceitos de roteamento, middlewares, controle de requisições e respostas HTTP.

---

## 🛠️ Ferramentas e Tecnologias

| Tecnologia / Ferramenta | Descrição |
| :--- | :--- |
| **JavaScript** | Linguagem de programação principal |
| **Node.js** | Ambiente de execução JavaScript no servidor |
| **Express** | Framework web para construção das rotas e APIs |
| **NPM** | Gerenciador de pacotes e dependências do Node.js |
| **Git** | Sistema de controle de versão distribuído |
| **GitHub** | Plataforma de hospedagem do código e colaboração |
